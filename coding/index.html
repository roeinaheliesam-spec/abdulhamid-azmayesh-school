اولین دستور با print()

نمایش متن روی صفحه

با print() می‌توانیم یک پیام یا مقدار را نمایش دهیم.

print("Hello, World!")
Hello, World!
🎯 چالش: پیام را تغییر بده تا نام خودت یا نام انجمن نمایش داده شود.

۰۲

متغیرها

نگهداری اطلاعات

متغیرها برای نگهداری چیزهایی مثل نام و سن استفاده می‌شوند.

name = "Ali"
age = 15
print(name)
print(age)
Ali
15
🎯 چالش: نام و سن دلخواه خودت را در دو متغیر ذخیره و نمایش بده.

۰۳

دریافت ورودی با input()

تعامل با کاربر

با input() از کاربر اطلاعات می‌گیریم و می‌توانیم از آن در پیام استفاده کنیم.

name = input("What is your name? ")
print("Hello", name)
What is your name? Ali
Hello Ali
🎯 چالش: نام کاربر را بپرس و به او پیام خوشامدگویی بده.

۰۴

شرط‌ها با if و else

تصمیم‌گیری در برنامه

if یک شرط را بررسی می‌کند و else وقتی اجرا می‌شود که شرط برقرار نباشد.

age = int(input("How old are you? "))
if age >= 18:
    print("18 or older")
else:
    print("Under 18")
تورفتگی خطوط در پایتون مهم است؛ خط‌های داخل شرط باید فاصله داشته باشند.
🎯 چالش: عددی بگیر و با if و else مشخص کن مثبت است یا غیرمثبت.

۰۵

عملگرهای مقایسه‌ای

مقایسه مقدارها در شرط‌ها

از > و < برای بزرگ‌تر و کوچک‌تر، از == برای مساوی و از != برای نامساوی استفاده می‌کنیم.

number = int(input("Enter a number: "))
if number > 10:
    print("Greater than 10")
else:
    print("10 or less")
🎯 چالش: برنامه را طوری تغییر بده که بررسی کند عدد واردشده از ۱۰ بزرگ‌تر است یا نه.

آشنایی با for و range()

for i in range(1, 11):
    print(i)
